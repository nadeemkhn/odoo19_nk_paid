Odoo 19.0

Website Quantity Buttons

Add quantity buttons on product cards and product detail pages with dynamic price update, quantity-based discount badges, and savings display.

Key Features

  • Quantity buttons on shop cards and product detail page.
  • Custom values like 1,2,3 or 1,2,3,4,5,6 (up to 6 buttons).
  • Custom label support: Unit, Pack, Box, etc.
  • Website-level default configuration with optional product-level override.
  • Automatic badge and savings line from quantity-based pricelist rules.
  • Responsive behavior for desktop and mobile.

Configuration Step by Step

Step 1. Install Module

  1. Install Website Quantity Buttons from Apps.
  2. Confirm dependency website_sale is installed.

Step 2. Configure Website Defaults

  1. Go to Website > Configuration > Websites.
  2. Open your website and select tab Quantity Buttons.
  3. Enable Website Quantity Buttons.
  4. Set Website Quantity Values (example: 1,2,3,4,5,6).
  5. Set Website Quantity Label (example: Unit).
Website-level configuration

Step 3. Optional Product-Specific Setup

  1. Go to Sales > Products > Products.
  2. Open the product and go to tab Website Quantity Buttons.
  3. Enable Website Quantity Buttons for that product.
  4. Set product-specific quantity values and label if needed.

Priority: if product-level is enabled, product settings are used first; otherwise website defaults are used.

Product-level override

Step 4. Configure Pricelist Rules

  1. Go to Sales > Products > Pricelists.
  2. Open the pricelist used by your website.
  3. Add rules with Min. Quantity values (2, 3, 4, 5, 6).
  4. Set discount or fixed price per quantity break.
  5. Use this pricelist on website to show discount badges and savings.
Pricelist quantity discount setup

Step 5. Verify in Storefront

  1. Open shop and product detail pages.
  2. Select different quantity buttons and verify live price update.
  3. Confirm discount badge and savings line appear for discounted quantities.

Technical Notes

  • Dependency: website_sale.
  • No core override; implemented via inherited views and frontend assets.
  • Compatible with Odoo multi-website setups.
